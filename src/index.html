DOKUMEN SEHARI-HARI

Alat PDF, sesuai kebutuhanmu.

Susun halaman, ambil teks, ubah gambar, atau atur kata sandi. File diproses di browser; aplikasi ini tidak menyediakan unggahan dokumen ke server.

Maksimal 25 MiB per file, 50 MiB per pekerjaan, dan 200 halaman. Batas lain mengikuti alat yang dipilih.

Pilih alat PDF

Menyiapkan alat PDF. Jika daftar belum muncul, periksa JavaScript dan akses berkas aplikasi lalu muat ulang halaman.

Tidak ada alat yang cocok. Ganti kata kunci atau pilih Semua alat.

Cara kerja

  1. Pilih alat dan file. Susunan file menentukan urutan hasil.
  2. Periksa pengaturan. Keterangan alat menjelaskan batas dan perubahan pada isi.
  3. Proses, periksa, lalu unduh. File sumber tidak ditimpa. Membuka atau menyimpan hasil mengikuti pengaturan browser.

Konversi teks memerlukan tulisan yang dapat dipilih. Tanda tangan berupa teks visual; crop mengubah batas tampilan dan tidak menghapus informasi tersembunyi.
